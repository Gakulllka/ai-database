# Поддержка каталога

Ветка `database` хранит каталог для подключения, инструкции скиллов, пакетные ресурсы и общие хуки Codex. Поддерживаемый процесс сравнения, проверки и публикации находится в [database-evolution](../../skills/database-evolution/SKILL.md). В [конфигурации обзора](../../config/database-evolution.json) указаны запросы и ограничения сбора.

Для повторного анализа используй карточки решений в [evolution/decisions](../evolution/decisions/) и свежий снимок. Метрики помогают отобрать кандидатов для проверки. Решение о применимости опирается на исходный материал и проверку поведения.

Для публикации сохраняй доказательство достаточной проверки, независимый просмотр и точный коммит. Публичные или синтетические примеры позволяют применять находку в другом проекте.
