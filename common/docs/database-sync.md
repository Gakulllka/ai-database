# Обновление Database

При подключении проекта читай [START HERE](https://github.com/Gakulllka/ai-database/tree/database). Проверь свежий коммит ветки `database` и используй его каталог, состав пакета и материалы вместе.

Когда в уже подключённом проекте существенна новая цель или подходящего скилла нет, обнови снимок, выбери подходящий пакет и выполни `setup` для корня проекта. Команда `check` показывает ревизии и состояние установленных файлов. Если изменился общий пакет, для тематических скиллов проверь совместимость с ним. Если GitHub недоступен, укажи, какая ревизия осталась локально, и продолжи с доступными материалами.

Для доработки самой Database смотри [database-evolution](../skills/database-evolution/SKILL.md). Согласованный объём изменений проверяй отдельно от пользовательского проекта и публикуй обычным обновлением ветки `database`.
