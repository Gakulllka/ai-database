# 1C Testing

> This file extends [common/testing.md](../common/testing.md) with 1C-specific content.

## Evidence levels

- Проверка XML и статические диагностики BSL подтверждают только свой предмет проверки.
- Синтаксическая проверка целевой платформой требует её версии и реальной конфигурации.
- Smoke проверяет запуск и конкретные действия; правильность расчётов доказывается отдельными сценариями с ожидаемыми значениями.
- Измеряй покрытие только доступным для проекта инструментом. Покрытие вспомогательных Python-скриптов не является покрытием BSL; недоступную метрику указывай явно.

## Business and regression scenarios

Выводи ожидания из требований независимо от реализации. Для периодических расчётов
включай обычный случай, границы периода, соседний период, отсутствие данных и повторный
запуск. Для изменений прав проверяй разрешённые и запрещённые действия нужных ролей;
для конкурентных операций — соответствующие многосеансовые сценарии.

## Environment

Применяй существующие средства проекта и его конфигурацию BSL Language Server.
Запись, проведение, удаление и обновление ИБ выполняются только в разрешённой среде
и в рамках поручения. Если среды нет, подготовь воспроизводимые ручные шаги и отметь
невыполненные проверки. Для отчёта разделяй состояние исходников и применённой ИБ.
