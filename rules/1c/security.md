# 1C Security

> This file extends [common/security.md](../common/security.md) with 1C-specific content.

## Server boundary and access rights

- Проверяй входные данные и полномочия на серверной границе; скрытая кнопка формы не является контролем доступа к операции.
- Учитывай роли, параметры сеанса и ограничения доступа к данным (RLS) при чтении и записи.
- Не включай привилегированный режим и не ослабляй роли, RLS или безопасный режим ради устранения ошибки доступа. Сохраняй обоснованные доверенные границы существующей конфигурации.
- `ВЫБРАТЬ РАЗРЕШЕННЫЕ` меняет состав доступных данных: применяй его по смыслу операции, не как универсальный способ скрыть неполноту расчёта.

## Queries and integrations

- Значения фильтров передавай параметрами; не соединяй пользовательский ввод с текстом запроса.
- Для динамических идентификаторов проверяй допустимые объекты и поля по метаданным.
- Учётные данные ИБ, подключения и MCP храни в локальных защищённых настройках. Исключай их из исходников, выгрузок, скриншотов и диагностических сообщений.
- Рассматривай внешние обработки, расширения и команды администрирования как исполняемый код с конкретными правами и целевой ИБ.
