# Godot и игры

Пакет для игровых задач, включая разработку на Godot, баланс и проверку механик с игроками.

Определи, что проверяешь в первую очередь. Это может быть работа сцены, игровое правило, экономика или понимание механики игроком. Выбери соответствующий скилл по описанию в пакете.

Для игрового баланса и плейтеста используй тематические скиллы из [пакета design](../design/README.md).
