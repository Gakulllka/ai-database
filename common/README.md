# Common

## Как улучшать Database

1. Если скилл не помог или подходящего скилла нет, исследуй задачу по первичным источникам. Проверь найденный способ на конкретном примере и выдели то, что пригодится в другом проекте.
2. Сверься со свежим [каталогом](catalog.json). Обнови скилл, который уже отвечает за эту задачу, или добавь новый в близкий по смыслу пакет. Создавай новую папку верхнего уровня с `pack.json` и записью в каталоге только для темы, которой среди пакетов нет.
3. Проверь, что скилл работает в целевом проекте с нужными ресурсами. Из полной копии запусти `node common/tools/database.mjs verify`. Публикуй проверенные изменения в согласованных пользователем границах, используя общедоступные или синтетические примеры. Добавляй новые коммиты в `database` с сохранением публичной истории и сверяй результат на GitHub.
