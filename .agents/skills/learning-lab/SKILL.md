# Learning Lab

1. Pick one finding and cite its source. State a prediction, the assumptions that matter, and a result that would overturn it.
2. Run a small check. Compare a baseline with one change under the same relevant conditions. Use a calculation, observation or actual run. Label invented inputs.
3. Test a different task with the same underlying mechanism. Pick its own measure of success and check one boundary where the rule might stop helping or its assumptions fail. Carry out authorized checks and identify any that remain hypothetical.
4. Lead with what happened and what the user can reuse. Show concrete results for both tasks and name the condition that limits transfer. Keep observations, predictions and explanations distinct.
