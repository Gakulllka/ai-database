# Якоря и статусы

По выбору направления см. [основной навык](../../../../skills/retro-3d-painted/SKILL.md).
Доска: [Ретро-3D — простая геометрия и рисованные текстуры](https://www.pinterest.com/thenybas/ретро-3d-простая-геометрия-и-рисованные-текстуры/).
Первичный реестр референсов хранится в исходном архиве проекта.

| Якорь | Когда смотреть | Статус и предел |
| --- | --- | --- |
| Пользовательский скриншот из исходного архива | Пропорции тыквы, рисованный объём, тёплый герой в холодной среде | Пользовательский ориентир; игра/автор/права неизвестны. Скрытый mesh по нему не установлен |
| [Plain sphere v5](../assets/plain-sphere-v5.jpg) | Продолжение конструкции головы | Пример требуемой простой основы данной тыквы; не универсальная форма всех моделей |
| [Final v5](../assets/final-v5.jpg) | Исходная художественная подача | Технически проверена, художественного принятия нет |
| [A/B первого прогона](../assets/texture-comparison.jpg) | Правка крупных масс текстуры | B спокойнее, но теряет часть долек; учебный кандидат, не предпочтительный эталон |
| [Масштабы первого прогона](../assets/target-scales.jpg) | Проверка цены фактуры в малом размере | Кропы реального WebGL, не новая генерация и не настоящий игровой viewport |
| [Оборот B](../assets/uv-seam.jpg) | Проверка UV-стыка | Негативный якорь: узкая линия остаётся при равенстве крайних texels |

Внешние кандидаты просмотрены и сохранены 17.11.2026: Wizard / Oli4_VH — крупные
знаки лица и бороды; два персонажа в зелёном / публикатор Thijs Peeters — экономная
форма и нарисованные детали; Mökki / Igma Studio — иерархия масс окружения.
Их конкретные персонажи, костюмы, палитры и предполагаемые budgets не канон.
Авторство/лицензии не независимо подтверждены; ссылки и точные оговорки в реестре.

## Неуспешные попытки самостоятельного 3D

По прямой итоговой оценке пользователя серия из пяти реконструкций не удалась.
Ошибки пяти попыток и выводы перечислены в
[разборе серии](failed-3d-studies.md). Используй их для диагностики текущего подхода.
Там же сохранён указатель на предшествующего Болотного фонарщика (248 tris),
которого пользователь назвал «неплохим примером»; это не означает принятия
последующей серии или доказательства точного воспроизведения референса.

Навык оформлен по прямому поручению пользователя, версия 0.1.1. Это архив
инструкций и опыта, не обученная модель и не художественное принятие примеров.
