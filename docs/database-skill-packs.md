# Каталог скиллов Database

Каталог устроен в три уровня. Сначала выбери тему, затем пакет, затем нужную
инструкцию внутри уже скачанного пакета. Пакет включает целые исходные папки
скиллов со справками, шаблонами, скриптами и другими файлами.

| Тема | Примеры пакетов |
| --- | --- |
| Разработка и инфраструктура | Языки, базы данных, 1С, DevOps |
| Качество, тесты и документация | Тестирование, ревью, регрессии, изменения документации |
| ИИ-агенты и рабочая среда | Оркестрация, настройка инструментов, память |
| Исследования и обучение | Поиск источников, учебные проверки, машинное обучение |
| Безопасность и соответствие требованиям | Ревью безопасности и отраслевые проверки |
| Игры, дизайн и медиа | Godot, баланс, плейтесты, дизайн и видео |
| Контент и публикации | Редактура, публикации и обработка документов |
| Операции и отраслевые задачи | Интеграции, согласования, логистика и рынки |

[Машиночитаемый каталог](../manifests/skill-pack-groups.json) хранит названия и
слова поиска на русском и английском. Явно названная платформа, например 1С или
Godot, повышает приоритет её пакета. Состав каждого пакета и его зависимости
берутся из [модулей установки](../manifests/install-modules.json). Папки
скомпонованы на уровне каталога. Ссылки вида `skills/<имя>/SKILL.md` сохраняют
свои адреса, включая пути к обновлениям ECC и локальным скиллам.

## Найти и скачать целый пакет

Выполняй команды из существующей копии ветки `database`.

```text
node scripts/skill-packs.js list
node scripts/skill-packs.js find "плейтест игры"
node scripts/skill-packs.js show game-playtest
node scripts/skill-packs.js fetch game-playtest --into .
```

Для ИИ добавь `--json`. Скачивание создаёт новую папку внутри существующего
каталога из `--into`. В ответе указаны путь новой папки и коммит GitHub.
Команда закрепляет одну версию репозитория и скачивает по ней целые каталоги
выбранных модулей и объявленных зависимостей. В `show` и `fetch` можно
указать ID всей темы, например `research-learning`.

Используй скачанную папку как источник инструкций и ресурсов. Дополнительные
ссылки в разделе «Связанные скиллы» могут вести в другой пакет. Для установки
в приложение используй действующий установщик из полной копии Database.
Сначала посмотри, какие файлы и зависимости он собирается установить.

```text
node scripts/ecc.js install --target codex --modules game-playtest --dry-run
```

## Первый запуск с GitHub

Если Database ещё нет локально, достаточно получить каталог и команду поиска.
Полные тексты скиллов придут только при скачивании выбранного пакета.

```text
git clone --filter=blob:none --depth 1 --single-branch --branch database --no-checkout https://github.com/Gakulllka/ai-database.git Database-catalog
git -C Database-catalog sparse-checkout set --no-cone /scripts/skill-packs.js /scripts/lib/skill-packs.js /manifests/skill-pack-groups.json /manifests/install-modules.json
git -C Database-catalog checkout --detach HEAD
node Database-catalog/scripts/skill-packs.js find "учебная лаборатория" --json
node Database-catalog/scripts/skill-packs.js fetch learning-workflows --into .
```

## Как добавлять скиллы

Добавь новый скилл в подходящий модуль установки. Уже существующий модуль
автоматически подхватит его в каталоге. Для нового модуля выбери ровно одну
тему и добавь название и слова поиска в `skill-pack-groups.json`. Запусти
`node --test tests/scripts/skill-packs.test.js`. Проверка сопоставляет каталог
с фактическими папками скиллов и показывает отсутствующие или лишние записи.
