# Blender

Пакет для работы со статичными моделями в Blender. Навык
[`blender-asset-workflow`](skills/blender-asset-workflow/SKILL.md) помогает
проверить сетку и UV, подключить текстуру, снять сопоставимые рендеры и
проверить экспорт. Для работы нужен доступный Blender. Для управления
открытой сценой можно использовать отдельно подключённый MCP.

Для художественной переработки текстур и разбора движений используй навыки
`model-texture-restyle` и `blender-motion-state-inspection` из пакета
[design](../design/README.md).
