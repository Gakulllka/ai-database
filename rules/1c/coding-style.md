# 1C / BSL Coding Style

> This file extends [common/coding-style.md](../common/coding-style.md) with 1C-specific content.

## Existing conventions and compatibility

- Сохраняй язык идентификаторов, отступы, области и структуру соседнего BSL-кода.
- Префиксы объектов, суффиксы, маркеры изменений и номера задач определяет проект.
- Проверяй версию платформы, режим совместимости и фактически встроенную БСП перед использованием API.
- Для `.os` сначала установи среду OneScript и её библиотеки: API платформы 1С и контексты управляемых форм там нельзя предполагать.

## Mutation and ownership

Языковое уточнение общего правила immutability: прикладные объекты 1С, табличные части,
наборы записей и данные форм штатно изменяются на месте. Используй их API с понятным
владельцем изменения и контролируемой записью. Не заменяй такую работу клонированием
объекта ради формального соблюдения immutability; побочные изменения входных коллекций
и запись в ИБ должны оставаться явными.

## Readability and maintenance

- Процедуры и переменные называй по предметному смыслу; параметры, результат и побочные эффекты должны быть понятны вызывающему коду.
- Разделяй получение данных, расчёт, запись и взаимодействие с формой там, где это упрощает сопровождение. Не дроби код на цепочку мелких обёрток ради формального ограничения длины.
- Комментарии объясняют бизнес-причину, ограничения и важные последствия; они не заменяют понятную структуру и не пересказывают каждую строку.
- Хороший и плохой примеры пользователя служат исходными свидетельствами. Уточни, что именно оценивается: корректность, читаемость или соответствие местным правилам. Проверяй выводы на других механизмах перед обобщением.

## Exceptions

- Перехватывай исключение для восстановления, освобождения ресурсов, отката своей транзакции или обработки на нужной границе.
- Не скрывай ошибку пустым `Исключение` или сообщением об успехе. При отсутствии обработки передавай ошибку выше.
- Доступность реквизита или метода выясняй по метаданным и версии API, а не через заведомо ошибочный вызов внутри `Попытка`.
