# Исследования и обучение

Пакет для поиска источников, освоения новых тем, практических проверок и создания скиллов.

Начни с вопроса, на который нужно ответить. Разделяй сведения из источников, свой вывод и результат проверки. Переноси в скилл знания, которые пригодятся в другой задаче и прошли пробный запуск.
