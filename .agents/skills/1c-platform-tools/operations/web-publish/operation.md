# Публикация 1С: ручной порядок

Исполняемые скрипты публикации из архива исключены: они автоматически скачивали
Apache, меняли серверную конфигурацию и включали широкий набор сервисов.

Выполняй публикацию только по поручению пользователя для явно выбранной базы
и сервера. Сначала установи версию платформы и веб-сервера, абсолютный ApachePath,
имя публикации, адрес привязки, порт и точный список разрешённых HTTP/WS/OData
сервисов. Для локальной разработки используй loopback, если иной адрес не согласован.
Не записывай пароль базы в `default.vrd`; настрой отдельный разрешённый способ
аутентификации. Публикация и установка сервера — отдельные действия.

Сохрани резервную копию текущих `httpd.conf` и дескриптора публикации. Подготовь
минимальный diff, проверь конфигурацию штатной командой сервера, затем примени
изменения в согласованное окно. Проверяй только разрешённый адрес. При неудаче
восстанови сохранённые файлы и прежнее состояние конкретного экземпляра сервера.
Не скачивай и не запускай Apache автоматически.
