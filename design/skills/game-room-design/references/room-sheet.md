# Лист комнаты и сверка ракурсов

В каталоге результата держи оригиналы ракурсов, схему сверху и лист просмотра, который открывается локально. В листе покажи кадры с понятными подписями и ссылками на PNG, план с камерами, точные фрагменты значимого реквизита и места действия. Для нескольких похожих предметов укажи число и порядок. Промпты сохраняй по требованиям генератора или когда они помогают повторить кадр.

## Что считать якорями

- Проёмы, мебель, длина прохода, принадлежность предмета стене и положение относительно соседнего предмета.
- Источники света, заметные рисунки, надписи, повторяющийся набор предметов.
- Новый реквизит обратных стен, особенно выключатели, ручки, сумки и вещи на краю кадров. Закрепляй предмет за одной точкой в комнате, даже если его видно только в одном ракурсе.

Начинай сверку с наиболее заметных якорей. Для каждого ракурса сначала спрогнозируй видимость по плану, затем открой PNG в полном размере и проверь. Например, если на соседнем кадре видно полотно двери и узкую полосу стены со стороны ручки, найди выключатель в этой полосе или объясни его перекрытие. Для зеркала сопоставь сторону отражения с направлением камеры. В миниатюре проверь, что реквизит поддерживает характер комнаты и фигура не потеряется на фоне.

## Машиночитаемая сверка

Положи рядом с листом `room.json`. Пути указывай относительно этого файла. Список ниже показывает форму для учебного примера. Если кадр 02 видит дверь, в поле заметки объясни, где находится её ручка или выключатель.

```json
{
  "plan": "plan.png",
  "sheet": "reference.html",
  "reference": "01",
  "views": [
    {"id": "01", "file": "01.png", "direction": "На стол и дверь"},
    {"id": "02", "file": "02.png", "direction": "От окна вдоль стены"}
  ],
  "anchors": [
    {
      "name": "Выключатель слева от двери",
      "views": {
        "01": {"status": "visible", "note": "Возле ручки"},
        "02": {"status": "occluded", "note": "Скрыт открытым полотном двери"}
      }
    }
  ]
}
```

Статусы `visible`, `occluded`, `out-of-frame` и `mismatch` описывают результат визуального просмотра. При `mismatch` укажи расхождение и исправь его либо сообщи, какая часть результата осталась непроверенной. Каждый якорь должен быть виден хотя бы в одном кадре завершённой серии. Минимум для полного обхода определяется формой комнаты и просьбой пользователя.

Для автоматической проверки нужен Python 3.9 или новее. Из каталога скилла запусти:

```text
python scripts/check_room_sheet.py <путь-к-room.json>
```

Скрипт проверяет локальные ссылки, структуру и контрольные суммы блоков PNG, полноту заметок. В проверяемом листе ссылки на файлы относительны HTML, без элемента `base`. Открой изображения в просмотрщике, чтобы проверить декодирование и содержание.
