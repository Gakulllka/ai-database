# 1C Agent Routing

> This file extends [common/agents.md](../common/agents.md) with 1C-specific content.

## Domain routing

- Поиск объекта и объяснение кода: основной агент или существующий `code-explorer`, с адресным чтением выгрузки.
- Изменение BSL: [1c-bsl-patterns](../../skills/1c-bsl-patterns/SKILL.md) вместе с правилами текущего проекта.
- Проверка изменения: [1c-reviewer](../../agents/1c-reviewer.md), с требованиями, diff и подтверждёнными зависимостями.
- Ошибка синтаксиса, сборки или загрузки: [1c-build-resolver](../../agents/1c-build-resolver.md), с точным журналом и версией среды.
- Проверка поведения: [1c-testing](../../skills/1c-testing/SKILL.md) и существующие средства проекта.

## Scope and handoff

Передавай роль, цель, исходники, требования и доступную среду. Отдельно обозначай,
разрешены ли только файлы, применение конфигурации или действия в ИБ.
Описание роли не предоставляет подключение или права. Используй поддерживаемый
механизм делегирования; при его отсутствии выполни применимые проходы локально.
Собирай результаты делегирования и отделяй прочитанные факты, гипотезы и реальные проверки.
