# Снятие публикации 1С: ручной порядок

Исполняемые скрипты снятия публикации из архива исключены. Определи абсолютный
каталог сервера, точное имя публикации и разрешённую область изменения.
Сохрани копии `httpd.conf` и дескриптора публикации. Подготовь точечное удаление
только выбранной публикации, проверь конфигурацию штатными средствами и выполни
изменение по поручению пользователя. Снятие веб-публикации не требует удаления
информационной базы или её данных. При неудаче восстанови копии и прежнее
состояние конкретного сервера; режим снятия всех публикаций по умолчанию отсутствует.
