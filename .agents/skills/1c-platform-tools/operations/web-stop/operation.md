# Остановка веб-сервера 1С: ручной порядок

Исполняемые скрипты остановки из архива исключены. Установи конкретный экземпляр
сервера по абсолютному пути исполняемого файла или идентификатору службы, его
публикации и влияние на пользователей. Останавливай его только в рамках
поручения пользователя и согласованного окна, штатным механизмом службы.
Не завершай процессы по общему имени и не затрагивай другие экземпляры Apache.
До остановки зафиксируй исходное состояние; план отката — запуск того же
экземпляра с прежней конфигурацией и проверка согласованных публикаций.
