# 1С

Пакет для разработки и сопровождения 1С. Подходит для работы с BSL, запросами, расширениями, формами, интеграциями, тестами и документацией.

Начни с точной конфигурации, нужного объекта и доступного источника данных. Выбирай проверку по задаче. Результат разбора исходников и результат проверки в целевой базе фиксируй отдельно.
