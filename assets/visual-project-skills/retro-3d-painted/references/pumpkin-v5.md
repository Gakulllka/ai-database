# Только текущая тыква: строгий контракт v5

При продолжении pumpkin-3d-web или её учебных копий сначала читай действующий
[style-guide v5](pumpkin-style-guide.md).

- Голова — чистый эллипсоид .94/.63/.71, центр Y=1.48, 192 triangles / 98
  уникальных геометрических позиций. Физические дольки, борозды, глазницы,
  вырезы, верхнее углубление и displacement запрещены. Уравнение поверхности
  проверяется валидатором с допуском 1e-9.
- detail_point() предназначена только для bake. В positions поступает point().
- Персонаж 466 при пределе 500; сцена 976 при пределе 1000. Это лимиты этой
  работы. V4 с физическими дольками и 1268 triangles отвергнута; 24/48 квадов
  и 128×64 — исторические требования, не актуальные ограничения.
- Base color/normal/ORM головы 512×256, другие карты 64–128. Modern light,
  roughness, нормали и художественная cavity AO-оценка разрешены. AO не ray trace.
- Пайплайн: Python/Pillow, native WebGL2, PNG и статический GLB. На момент
  прогона DCC не использовался, рига нет, движение исходного viewer — part
  transforms. Не обещай полноценную ходьбу или проверенный импорт в движок.
- Встроенный браузер проверяет по HTTP. Прямой file:// запрещён его политикой;
  не обходить. Это ограничение среды просмотра, не требование эстетики.

В первом прогоне изменена только base color кожи. Лицо защищено точной маской,
свет и normal/ORM сохранены. Clay-viewports совпали без пиксельных различий.
Подробности в [разборе текстур](texture-comparison.md).
До прямой оценки пользователя B остаётся кандидатом. Исходную v5 не перезаписывать.
