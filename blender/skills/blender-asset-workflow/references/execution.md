# Запуск Blender и управление сценой

## Фоновый запуск

Для локальных файлов, воспроизводимой правки материалов и рендера используй
`bpy` из Blender. Укажи абсолютные пути и порядок аргументов. Blender выполняет
их слева направо. В примере файл открывается до скрипта, а свои параметры
скрипт получает после `--`.

```text
blender --background --factory-startup --disable-autoexec "<input.blend>" --python-exit-code 17 --python "<script.py>" -- "<output-dir>"
```

Для формата импорта вместо пути к `.blend` вызови оператор импорта в скрипте.
Сделай скрипт и сообщения об ошибках пригодными для повторного прогона. Проверь
код завершения, ожидаемые файлы и изобразительный результат.

Для геометрии с модификаторами получи вычисленный объект через dependency graph.
Если создаёшь временную сетку через `to_mesh()`, освободи её через
`to_mesh_clear()`. Для GLB проверь, что изменения узлов представимы в glTF.
Произвольные узловые эффекты могут потребовать запекания.

22 ноября 2026 года на Windows в Blender 4.5.13 LTS проверены импорт GLB, чтение триангуляции
и координат UV, замена узла цвета, Cycles-рендеры при общей камере, упаковка
PNG и повторное открытие `.blend` с проверкой геометрии и UV. Экспорт GLB
и подключение живого MCP описаны по документации.

- [Blender 4.5. Аргументы командной строки](https://docs.blender.org/manual/en/4.5/advanced/command_line/arguments.html)
- [Blender 4.5. Python API сетки](https://docs.blender.org/api/4.5/bpy.types.Mesh.html)
- [Blender 4.5. Поддержка glTF](https://docs.blender.org/manual/en/4.5/addons/import_export/scene_gltf2.html)

## Открытая сцена через MCP

Если нужно работать в открытой сцене, проверь, что сервер MCP и совместимое
дополнение подключены. Вызови описанные сервером операции чтения сцены и
проверь совпадение с нужным файлом перед редактированием. Для сохранения
попроси Blender записать копию по согласованному пути и проверь её чтением.

Для новой интеграции проверь исходники, конкретные версии сервера и
дополнения, настройки внешних интеграций и разрешения. У одного из
общественных коннекторов MCP for Blender есть снимки окна, чтение сцены и
выполнение Python. Возможности конкретного соединения устанавливаются
проверкой в текущей среде.

- [MCP for Blender. Документация проекта](https://github.com/ahujasid/mcp-for-blender)
