# Тыквенный странник v5 — простая форма, выразительные карты

Строгое уточнение пользователя: голова — слегка изменённый шар с текстурой.
**Геометрические дольки, борозды, вырезы, глазницы и углубление у стебля запрещены.**
Эта логика обязательна при дальнейших правках этого персонажа. Качество материала
не является основанием добавлять геометрию деталей. Изменить правило можно только
по явному новому поручению пользователя.

Модель головы — обычный эллипсоид с радиусами .94/.63/.71, Y-центр 1.48.
16 сегментов × 7 рядов: 192 треугольника, 98 геометрических вершин после сварки
UV-шва и полюсов. Ни частоты восьми долек, ни смещения вершин по картам в ней нет.
Валидатор строго проверяет уравнение эллипсоида у каждой вершины. Нормали
сглажены, чтобы малое число плоскостей не разрушало округлую форму.

Весь персонаж — 466 треугольников, сцена — 976. Бюджеты: 500 и 1000.
Руки, варежки, ботинки, подошвы и навершие упрощены; лишние манжеты удалены.
Числа 1268/1778 и физические дольки v4 пользователем отвергнуты.

Весь характер тыквы создают рисованный base color, мягкий normal-map рельеф
и затенение в картах. detail_point() — только виртуальная поверхность bake,
она не должна передаваться в mesh positions. Её нормальный рельеф ослаблен
до 2.5% радиуса; геометрического углубления у полюсов нет даже в этом источнике.
Base color / normal / ORM головы остаются 512×256; другие карты 64–128.
Современные свет, roughness, AO-оценка и фильтрация остаются допустимыми.
AO здесь художественная cavity-оценка, не ray trace. Источник: source/bake-v5.json.

При проверке обязательно смотреть «Текстуры» off: голова должна оставаться
чистым шаром/эллипсоидом без долек. «Сетка» проверяет скромный бюджет, а
включение карт возвращает рисунок и видимость борозд. Это правило данной работы,
не универсальный запрет для других 3D-персонажей проекта.

Предыдущие варианты сохранены в versions/, включая v4-1268tri.zip.
Финальная v5 требует художественной оценки пользователя, принятие не заявляется.
